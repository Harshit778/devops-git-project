# DevOps Git Version Control Project

## Project Overview

This project demonstrates the use of Git and GitHub for managing a DevOps project using version control best practices.

The project covers repository initialization, branching, commits, pull requests, documentation, `.gitignore`, and Git tags.

## Objectives

- Understand Git version control.
- Create and manage Git branches.
- Use meaningful commits.
- Work with feature branches.
- Use Pull Requests for merging changes.
- Use `.gitignore`.
- Create Git tags for project versions.
- Document project tasks using Markdown.

## Tools Used

- Git
- GitHub
- Visual Studio Code
- Markdown
- Git Bash

## Branching Strategy

This project uses three types of branches:

- `main` - Stable and final version.
- `dev` - Development and integration branch.
- `feature/project-documentation` - Feature development branch.
