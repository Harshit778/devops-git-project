# Project Tasks

## Task 1 - Git Repository Setup

- Created the project directory.
- Initialized Git repository using `git init`.
- Renamed the default branch to `main`.

## Task 2 - GitHub Repository

- Created a GitHub repository.
- Connected the local Git repository with GitHub.

## Task 3 - Project Documentation

- Created `README.md`.
- Added project overview.
- Added project objectives.
- Added tools and Git workflow.

## Task 4 - Git Ignore

- Created `.gitignore`.
- Added unnecessary files and folders to `.gitignore`.
- Added environment files such as `.env`.
- Added temporary and IDE files.

## Task 5 - Development Branch

- Created the `dev` branch.
- Pushed the `dev` branch to GitHub.

## Task 6 - Feature Branch

- Created a feature branch named:
  
  `feature/project-documentation`

- Made documentation changes.
- Created meaningful commits.

## Task 7 - Pull Request

- Created a Pull Request from the feature branch to `dev`.
- Reviewed the changes.
- Merged the Pull Request into `dev`.

## Task 8 - Main Branch

- Created a Pull Request from `dev` to `main`.
- Reviewed the changes.
- Merged the Pull Request into `main`.

## Task 9 - Git Tag

- Created the first version tag:
  
  `v1.0.0`

- Pushed the tag to GitHub.

## Final Outcome

The project demonstrates a basic Git and GitHub DevOps workflow using:

- Git repository
- Branches
- Commits
- Feature branches
- Pull Requests
- `.gitignore`
- Markdown documentation
- Git tags
- GitHub
